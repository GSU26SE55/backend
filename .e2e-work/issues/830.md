# #830 — [BatteryService][IoT][Mapping] A site device is implicitly authorized for every battery at that site

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/830

---

## Component
IoT device-to-battery authorization

## Evidence
The IotDevice model has no per-device battery relation. Provisioning returns all site assets, and ingestion checks only that payload battery and device share a site.

## Actual
Any compromised/misconfigured device at a site can submit telemetry for every battery at that site, so device identity does not constrain its physical mappings.

## Expected / acceptance
Persist explicit device↔battery/channel mappings, return only assigned assets at provision time, validate each reading against that mapping for HTTP/MQTT, and add cross-device same-site denial tests.
