# #811 — [BatteryService][IoT][OTA] Firmware update log accepts invalid states and regressive transitions

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/811

---

## Phần bị lỗi
IoT firmware update status command/state machine.

## Bằng chứng
`UpdateIotFirmwareUpdateLogCommand` không validation; `DeviceLifecycleHandlers.cs:271-310` ghi thẳng status/bytes. Enum hợp lệ chỉ 1..7 nhưng handler có thể nhận 999, bytes âm, terminal Success→Downloading và không đảm bảo CompletedAt/current firmware nhất quán.

Runtime full OTA bị chặn vì không có release/hardware, nhưng source path deterministic và không có transition guard.

## Ảnh hưởng
OTA audit/progress bị corrupt, rollback/failure monitoring sai và device firmware version không đáng tin.

## Expected
Whitelisted enum và forward-only state machine; bytes 0..total; terminal immutable; completion atomically cập nhật timestamps/version.

## Acceptance criteria
- Reject enum invalid, negative/overflow bytes và transition lùi.
- Idempotent duplicate status.
- Tests cho success/failure/cancel terminal và concurrent updates.
