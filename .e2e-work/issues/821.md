# #821 — [BatteryService][NotificationService][TicketService] Battery lifecycle events have no consumers

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/821

---

## Component
Battery lifecycle integration contracts

## Evidence
`BatteryAssetLifecycleEvents.cs:5-30` names Notification welcome/transfer and Ticket cache/reroute subscribers. Create/transfer handlers produce these events, but NotificationService and TicketService contain no corresponding MassTransit consumers.

## Actual
After outbox relay support is corrected, lifecycle messages are still unhandled: customer notifications are absent and Ticket's battery ownership/site cache is not refreshed or rerouted.

## Expected / acceptance
Implement idempotent consumers and bindings in the declared services, define failure/retry semantics, and add a broker integration test from Battery commit through both downstream persisted effects.
