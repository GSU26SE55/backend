# #746 — [IoT][MQTT] Telemetry documented as QoS 1 is actually published with QoS 0

Priority: priority: P3
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/746

---

## Tóm tắt
API publish nhận tham số qos nhưng bỏ qua; PubSubClient publish dùng QoS 0, trong khi header/docs cam kết QoS 1. Mất kết nối có thể làm mất telemetry mà caller nghĩ đã được broker ACK.

## Bằng chứng
`mqtt_client.cpp:286-310` có `(void)qos`; header docs lines 53/59/62/66 ghi QoS1.

## Tái hiện
Capture MQTT packet/PUBACK khi publish telemetry với qos=1; packet là QoS0 và không PUBACK.

## Mong đợi
Dùng client hỗ trợ QoS1 thật hoặc sửa contract + reliability design; test packet-level và reconnect.
