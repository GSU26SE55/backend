# #822 — [Security][Secrets] Tracked env.prod.example contains an apparent live Discord webhook

Priority: priority: P1
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/822

---

## Component
Repository secret management

## Evidence
A secret-pattern scan found an apparent complete Discord webhook in tracked `env.prod.example`, present in repository history. The value is intentionally omitted from this issue.

## Impact
Anyone with repository/history access may invoke the webhook until it is revoked. Merely replacing the current file does not invalidate the exposed credential.

## Expected / acceptance
Immediately revoke/rotate the webhook, replace it with a non-secret placeholder, purge history where policy requires, audit webhook activity, and enable push/PR secret scanning with a regression fixture that cannot contain live credentials.
