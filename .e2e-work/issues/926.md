# #926 — [AuthService][2FA SMS][Outbox] Endpoint returns 200 but never commits SendSmsCommand

Priority: priority: P1
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/926

---

## Component

`AuthService` 2FA SMS fallback → Auth outbox → `SmsService`.

## Summary

`POST /api/auth/login/2fa/sms` stores an OTP in Redis and asks `IMessageProducerService` to publish `SendSmsCommand`, then returns 200. In AuthService that interface is replaced by an outbox writer which only adds an entity to the DbContext; the handler never calls `SaveChangesAsync`. The row is discarded with the request scope, no SMS is published, and the user is falsely told the OTP was sent.

## Evidence

- `Request2FASmsCommandHandler.cs:52-60` stores OTP and calls `_messageProducer.PublishAsync`.
- `Request2FASmsCommandHandler.cs:62-68` returns success without saving a unit of work/DbContext.
- `services/AuthService/src/AuthService.Infrastructure/DependencyInjection/ManageDependencyInjection.cs:31-38` replaces the producer with the Auth outbox implementation.
- `OutboxMessagePublisher.cs:23-37` only adds an outbox entity; it neither publishes directly nor saves changes.
- There is no direct handler/integration test for `Request2FASmsCommand`.

## Reproduction

1. Create a valid 2FA challenge for an account with verified phone number.
2. Call `POST /api/auth/login/2fa/sms`.
3. Observe HTTP 200 and the message that OTP was sent.
4. Inspect `outbox_messages`: no persisted `SendSmsCommand` row exists.
5. SmsService receives nothing, while the OTP remains in Redis and expires unused.

## Impact

- SMS fallback is non-functional despite a success response.
- A user without TOTP/backup code can be locked out.
- Retry creates more OTP state without a deliverable message.

## Acceptance criteria

- Persist the outbox row in the request transaction before returning success.
- Keep Redis OTP and outbox state consistent when DB commit fails.
- Return a controlled failure rather than “sent” if durable enqueue fails.
- Add integration coverage for outbox row, relay, and SmsService consumer.
- Add DB-failure and retry/idempotency tests.
