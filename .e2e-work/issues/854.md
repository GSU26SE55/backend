# #854 — [BatteryService][IoT][Security] Legacy SensorIngest key bypasses environmental scope and device identity

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/854

---

## Component
Battery API-key authentication

## Evidence
`ApiKeyAuthenticationHandler.cs:54-82` applies scopes/device/site claims only to per-device keys. The legacy branch at 85-103 compares only the global SensorIngest key and grants System; lines 123-125 explicitly ignore scope metadata. Ambient and incident endpoints require EnvironmentalIngest.

## Runtime reproduction
With invalid bodies (zero mutation): wrong key returns 401; configured legacy SensorIngest key reaches validation and returns 400 for both ambient and incident endpoints instead of 403.

## Impact
One legacy telemetry key can enter environmental safety handlers with no device/site identity; combined with #806 it has arbitrary-site blast radius.

## Expected / acceptance
Restrict/remove/feature-flag legacy credentials, enforce endpoint scope for every key path, require exact device/site identity for environmental writes, rotate the global key, and test all scope combinations.
