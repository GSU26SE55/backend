# #813 — [Production][Security] Compose exposes databases, broker UI, services and monitoring on all host interfaces

Priority: priority: P1
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/813

---

## Component
Production Docker Compose / network perimeter

## Evidence
`docker-compose.prod.yml` publishes PostgreSQL 5432, RabbitMQ management, every microservice HTTP port, Prometheus, Grafana and Alertmanager without a loopback bind. Only the Gateway should normally be an internet-facing application entry point.

## Actual
A host-level deployment exposes internal control/data planes and permits callers to bypass Gateway routing, throttling and perimeter policy. RabbitMQ UI, metrics and direct service endpoints become reachable wherever the host firewall permits.

## Expected / acceptance
Remove internal `ports` in favor of `expose`/private networks, publish only intended ingress endpoints, document firewall assumptions, and add a rendered-compose security test asserting internal ports are not host-bound.
