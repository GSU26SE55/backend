# #784 — [BatteryService][IoT][MQTT] Provisioned device credentials cannot authenticate to the broker

Priority: priority: P1
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/784

---

## Tóm tắt
API create/provision sinh MQTT username/password và trả cho thiết bị nhưng không đồng bộ credential vào Mosquitto; broker host/port còn null. Credential vừa cấp không thể connect. Ngoài ra username bị lowercase trong khi topic dùng uppercase DeviceCode, xung đột ACL case-sensitive.

## Bằng chứng runtime
- Tạo device `E2E-IOT-230605`: API 201, có mqttUsername/password nhưng mqttBrokerHost và mqttBrokerPort null.
- Dùng đúng credential đó publish tới broker runtime: `Connection Refused: not authorised`, exit 5.
- Cùng broker, static `backend-bridge` publish exit 0.
- `infra/mqtt/mosquitto/passwd` chỉ chứa backend-bridge.

## Bằng chứng source
- `CreateIotDeviceCommandHandler.cs:38-67` chỉ generate/hash/save DB, không provision broker.
- `IotApiKeyService.cs:98-103` tạo lowercase username.
- ACL `infra/mqtt/mosquitto/acl.conf:23-38` dùng `solar/%u/...`; firmware topic dùng uppercase DeviceCode.

## Acceptance criteria
- Create/rotate/revoke đồng bộ broker atomically hoặc qua provisioning job có trạng thái rõ.
- Trả broker endpoint usable.
- Chuẩn hóa identity/ACL casing.
- E2E dùng credential response connect, publish own topic; cross-device topic bị deny.
