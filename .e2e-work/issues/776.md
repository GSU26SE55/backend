# #776 — [AuthService][Security] OAuth token introspection is anonymous and unthrottled

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/776

---

## Tóm tắt
`POST /api/auth/introspect` được mô tả cho resource server nhưng không có resource-server authentication, API key, mTLS, `[Authorize]` hay rate-limit. Internet client có thể dùng endpoint như token-status oracle và tạo tải xác minh chữ ký/Redis.

## Bằng chứng source
- `AuthController.cs:467-480` không có authorization/rate-limit attribute.
- `IntrospectTokenCommandHandler.cs:25-76` verify JWT, query revocation Redis và trả active/sub/iat/exp.
- Rate limiting chỉ opt-in bằng endpoint attributes; không có global limiter cho route này.

## Bằng chứng runtime
Gửi 12 request liên tiếp không Authorization nhưng body chứa access token hợp lệ: cả 12 trả 200 và `active=true`, không có 401/429.

## Expected
Theo security boundary của token introspection, chỉ protected resource đã xác thực được gọi; endpoint cần throttling và không trở thành public token oracle.

## Acceptance criteria
- Bảo vệ bằng client credential/API key/mTLS riêng cho internal services.
- Rate-limit và audit calls; test anonymous 401, invalid client 401/403, valid resource server 200.
