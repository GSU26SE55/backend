# #861 — [Backend][Helm][Security] All application containers run as root and the security helper is unused

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/861

---

## Component
Dockerfiles and Helm pod security

## Evidence
All nine backend Dockerfiles omit USER. Runtime inspection confirms Gateway, Auth, Battery, Ticket, Notification, File, Email, SMS and Audit run as root. Helm defines `solar.podSecurityContext` with non-root/seccomp, but no workload includes it; application containers also omit capability drop, read-only root filesystem and service-account token opt-out.

## Impact
Any application RCE gains container root and a larger node/cluster credential attack surface.

## Expected / acceptance
Set non-root UID/GID in images and pods, apply RuntimeDefault seccomp, drop all capabilities, disable privilege escalation and unnecessary SA tokens, use read-only root filesystem with explicit writable mounts, and enforce via rendered-manifest policy tests.
