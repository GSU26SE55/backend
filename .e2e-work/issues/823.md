# #823 — [Infrastructure][Grafana][Security] Public staging Grafana uses a hard-coded administrator password

Priority: priority: P1
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/823

---

## Component
Helm monitoring configuration

## Evidence
`deploy/helm/solar-battery/values-staging.yaml` enables a public TLS Grafana ingress and hard-codes `adminPassword: Admin@123`. Default values also contain a predictable monitoring password when enabled.

## Actual
Every deployment made from the checked-in values shares a known administrator credential exposed in source control.

## Expected / acceptance
Load an independently generated password from a Kubernetes Secret/external secret manager, remove predictable defaults, rotate deployed credentials, and add chart-policy checks rejecting literal admin passwords.
