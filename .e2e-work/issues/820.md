# #820 — [ApiGateway][RateLimit] Authenticated requests never use the user partition

Priority: priority: P3
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/820

---

## Component
ApiGateway rate limiting

## Evidence
`GatewayRateLimitingExtensions.cs:24-27` searches for claim `UserId`. AuthService `JwtHelper.cs:43-47` emits `ClaimTypes.NameIdentifier` and `AccountId`, not `UserId`.

## Actual
Authenticated requests fall back to the IP bucket. Users behind one NAT/Gateway address share the same quota, while one user switching addresses evades the intended per-user partition.

## Expected / acceptance
Use the canonical account claim shared by token issuance and validation, fail safely when absent, and add signed-token tests asserting distinct user and IP partitions.
