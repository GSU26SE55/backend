# #860 — [IoT][Simulator][Offline Queue] Partial JSONL crashes flush and compaction is non-atomic

Priority: priority: P3
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/860

---

## Component
IoT simulator offline queue

## Evidence
`tools/simulator/esp32_simulator.py:94-100` eagerly json.loads every line with no quarantine; the main loop calls drain uncaught. `remove_first` truncates the live file and rewrites it without temp file, fsync or atomic rename.

## Deterministic reproduction
A valid line followed by a partial JSON line yields queue_size=2 then `JSONDecodeError`; the simulator exits when connectivity resumes. A crash/disk-full during compaction can erase remaining telemetry.

## Expected / acceptance
Use framed/checksummed durable records, quarantine corrupt/partial entries while continuing, compact via temp+fsync+atomic rename, bound the queue, and test corrupt tail/middle plus crash/restart.
