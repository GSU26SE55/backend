# #780 — [BatteryService][AI-Module] Ai MinReadings configuration violates the exact 30-row model contract

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/780

---

## Tóm tắt
`Ai:MinReadings` vừa được dùng làm threshold vừa làm số row gửi sang AI. AI schema yêu cầu chính xác 30, nên mọi cấu hình khác 30 làm prediction bị reject liên tục.

## Bằng chứng source/runtime
- `AiOptions.cs:31-32` expose MinReadings.
- `SohPredictionBackgroundService.cs:106-127` dùng `Take(MinReadings)` và gửi toàn bộ.
- AI `predict.py:91-99` yêu cầu `WINDOW_SIZE=30`.
- REST 31 rows trả 422; gRPC 29 rows trả INVALID_ARGUMENT.

## Actual / Expected
- Actual: MinReadings=29 hoặc 31 đạt threshold rồi gửi payload sai; worker nhận null và prediction dừng.
- Expected: payload WindowSize cố định 30; threshold/min history là config riêng và options phải validate.

## Acceptance criteria
- Startup validation chặn cấu hình bất hợp lệ hoặc tách hai option.
- Test các giá trị 29/30/31 và assert luôn gửi đúng 30.
