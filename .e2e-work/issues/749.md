# #749 — [IoT] Oversized identity is persisted to NVS before being truncated only in RAM

Priority: priority: P3
State: OPEN

## Tóm tắt
Device code/key quá dài được ghi nguyên vào NVS rồi chỉ truncate buffer RAM. CLI báo thành công nhưng reboot có thể load/fail/fallback khác trạng thái đang chạy.

## Bằng chứng
`firmware-esp32/src/identity/device_identity.cpp:66-90` và CLI provisioning path.

## Tái hiện
Provision identity vượt buffer, quan sát runtime truncated, reboot và đọc lại NVS; identity/credential không nhất quán.

## Mong đợi
Validate length/charset trước mọi persist, reject input invalid, transactionally store exact normalized value và test reboot boundary.
