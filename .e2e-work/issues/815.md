# #815 — [AuditAggregatorService][ApiGateway][Kubernetes] Helm disconnects Audit from gateway, PostgreSQL and RabbitMQ

Priority: priority: P1
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/815

---

## Component
AuditAggregatorService Helm integration

## Evidence
The Helm Gateway reverse-proxy ConfigMap defines Auth/File/Battery/Ticket/Notification/SMS destinations but no Audit destination. The shared NetworkPolicy lists omit Audit from Gateway ingress, PostgreSQL ingress, RabbitMQ ingress and Prometheus access.

## Actual
Under the chart's default-deny policy, Audit cannot reach its database/broker and Gateway cannot route to it. The missing override also leaves the Gateway's localhost Audit destination in effect.

## Expected / acceptance
Add the Audit service/port to Gateway destinations and every required network-policy selector, include monitoring discovery, and add a Helm deployment smoke test covering Audit readiness and a routed Audit request.
