# #806 — [BatteryService][IoT][Security] Environmental API key can submit data for any site

Priority: priority: P1
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/806

---

## Phần bị lỗi
Ambient readings và environmental incidents authorization.

## Runtime repro
Thiết bị thuộc Site A với API key scope 15 gửi ambient hợp lệ cho một Site B đang tồn tại: HTTP 201, inserted/data=1. Gửi site GUID không tồn tại trả 500 FK thay vì 4xx.

## Nguyên nhân
- `AmbientReadingsController.cs:58-69` chỉ kiểm scope, không bind claim `iot:site_id`.
- `BatchIngestAmbientReadingsCommandHandler.cs:27-48` dùng request SiteId trực tiếp, không existence/ownership.
- Cùng pattern ở `EnvironmentalIncidentsController.cs:68-78` và `EnvironmentalIncidentCommandHandlers.cs:31-105`.
- Sensor ingest đã kiểm device-site tại `BatchIngestSensorReadingsCommandHandler.cs:172-207`.

## Ảnh hưởng
Thiết bị bị compromise có thể đầu độc ambient/safety data hoặc tạo incident cho tenant/site khác.

## Expected
Site lấy từ authenticated device/claim hoặc request SiteId phải exact match; unknown/cross-site trả 403/404, không 500.

## Acceptance criteria
- Cross-site ambient và incident đều bị chặn.
- Same-site vẫn 201.
- Unknown site là controlled 4xx.
- Tenant/site authorization integration tests.
