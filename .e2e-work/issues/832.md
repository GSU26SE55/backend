# #832 — [IoT][OTA][Rollback] Failed boot-partition switch permanently disables rollback

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/832

---

## Component
ESP32 OTA state machine

## Evidence
`ota_update.cpp:153-183` clears pending state and marks rollback before verifying that the boot partition switch succeeds.

## Actual
If selecting the boot partition fails, persistent state says rollback is already handled and the next boot cannot safely retry/recover, potentially leaving the device on the bad image path.

## Expected / acceptance
Commit rollback state only after boot-partition selection succeeds, preserve recoverable pending state on failure, and add native fault-injection tests for each ESP-IDF error return.
