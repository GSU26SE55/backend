# #828 — [EmailService][Production] Admin invite falls back to localhost despite configured WebBaseUrl

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/828

---

## Component
Admin invite email consumer

## Evidence
`SendAdminInviteConsumer.cs:73-80` reads `AdminInvite:AcceptUrlBase` or `Frontend:AcceptInviteUrl`, but ignores `Frontend:WebBaseUrl`. Checked-in Compose/env templates provide only `Frontend__WebBaseUrl`.

## Reproduction
Configure `Frontend:WebBaseUrl=https://app.example.com` without the two undocumented keys and render an invite. The URL uses `http://localhost:5173/auth/accept-invite`.

## Expected / acceptance
Derive the public route from WebBaseUrl or fail startup in Production when missing; never use localhost in production; add configuration-contract and rendered-email tests.
