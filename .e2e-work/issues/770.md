# #770 — [AuthService][TicketService] Staff skill changes are never synchronized

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/770

---

## Tóm tắt
TicketService có consumer `StaffSkillsUpdatedEvent`, nhưng cả add và delete skill trong AuthService đều không publish event. Routing/assignment theo kỹ năng dùng dữ liệu cũ vĩnh viễn.

## Bằng chứng source
- `AddStaffSkillCommandHandler.cs:20-76` và `DeleteStaffSkillCommandHandler.cs:19-32` chỉ save local.
- Orphan consumer: `TicketService.Infrastructure/Consumers/AccountSyncConsumer.cs:204-229`.
- Contract: `shared/src/SharedContracts/Events/StaffSkillsUpdatedEvent.cs`.

## Tái hiện
Thêm/xóa skill cho Staff tại AuthService rồi truy vấn hoặc chạy auto-assignment ở TicketService; danh sách Skills không đổi.

## Acceptance criteria
- Publish full current skill set qua Auth outbox sau commit.
- Ticket consumer cập nhật idempotent.
- Integration test add, delete và duplicate delivery.
