# #735 — [IoT][Security] HTTPS ingestion and OTA disable TLS certificate verification

Priority: priority: P1
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/735

---

## Tóm tắt
Firmware gọi `setInsecure()` cho cả HTTPS API và OTA, chấp nhận mọi certificate. Kẻ MITM có thể giả response firmware-check và artifact có SHA tương ứng để flash firmware độc hại.

## Bằng chứng
`firmware-esp32/src/net/http_client.cpp:235-240`, `firmware-esp32/src/ota/ota_update.cpp:186-190`.

## Tái hiện
Đặt DNS/proxy tới HTTPS server dùng self-signed certificate và response hợp lệ. Firmware vẫn kết nối/download.

## Mong đợi
Xác minh CA/certificate hostname hoặc certificate/public-key pinning; OTA cần chữ ký bất đối xứng độc lập với SHA transport. Thêm negative integration test certificate giả.
