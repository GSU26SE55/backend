# #862 — [Production][Supply Chain] Floating latest image tags make deployments non-reproducible

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/862

---

## Component
Production Compose and Helm image provenance

## Evidence
`docker-compose.prod.yml` uses floating latest tags for TimescaleDB, MinIO, Prometheus/Grafana/Tempo/Alertmanager/Loki, exporters and agents. Helm defaults every application image to `latest` with Always pull and also floats infrastructure images.

## Actual
The same manifest can deploy different unreviewed bytes over time, break compatibility without a code change and prevents deterministic rollback/SBOM-to-runtime attribution.

## Expected / acceptance
Pin application images to immutable Git SHA and third-party images to digest/version, automate reviewed upgrades, record SBOM/provenance, and add CI policy rejecting floating tags in production-rendered manifests.
