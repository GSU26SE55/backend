# #725 — [BatteryService] Outbox relay rejects emitted integration event types and can poison the batch

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/725

---

## Tóm tắt
Outbox relay chỉ map 7 event type nhưng application/consumer cùng service ghi thêm nhiều event hợp lệ. Các row bị đánh `Unknown event type`, không publish; query lại không loại row vượt max retry nên có thể chiếm batch cũ mãi.

## Bằng chứng
- Map/relay: `OutboxRelayService.cs:16-34,48-69`
- Event bị thiếu: `AlertLinkToTicketRejectedEvent`, `AlertLinkedToTicketEvent`, `EnvironmentalIncidentDetectedEvent`, `EnvironmentalIncidentResolvedEvent`, `BatteryAssetCreatedEvent`, `BatteryAssetTransferredEvent`.
- Writers: `LinkAlertToTicketConsumer.cs:51,83,96`, `EnvironmentalIncidentCommandHandlers.cs:103,201,253`, `CreateBatteryAssetCommandHandler.cs:120`, `TransferBatteryAssetOwnerCommandHandler.cs:73`.

## Tái hiện
Chạy một producer flow rồi relay. Row tăng Failed/LastError=Unknown, consumer không nhận; các row sau có nguy cơ starvation.

## Mong đợi
Registry đầy đủ, retry terminal/dead-letter rõ ràng và test parity tự động giữa writer/event map.
