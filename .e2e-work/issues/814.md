# #814 — [Kubernetes][NetworkPolicy][Security] Empty selectors defeat default-deny isolation

Priority: priority: P1
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/814

---

## Component
Helm NetworkPolicy

## Evidence
`deploy/helm/solar-battery/templates/shared/network-policy.yaml` contains:
- `namespaceSelector: {}` in ingress rules described as Traefik-only;
- `from: []` for port 8080;
- broad `podSelector: {}` / namespace combinations for monitoring.

Rendered Helm manifests confirm these are emitted unchanged.

## Actual
Empty selectors match every namespace/source in the relevant rule, so cluster workloads can reach backend/Gateway ports despite the chart claiming default-deny isolation.

## Expected / acceptance
Select ingress-controller and monitoring namespaces/pods using explicit immutable labels, remove unrestricted `from: []`, render the chart in CI, and test allowed and denied pod-to-pod paths.
