## Component
AI prescription → Battery alert → Ticket saga

## Evidence
`SohPredictionBackgroundService.cs:246-258,322-338` receives safety warnings/SOP references but text serialization keeps only prescription, steps, PPE and human-verification. `BatteryAnomalyDetectedV2Event` sends `AiActionSteps=null`; saga state/activity retain only `AiPrescription`.

## Reproduction

## Expected / acceptance
Version the event to carry structured steps, safety warnings and SOP references end-to-end; persist/render them in Ticket; add a broker saga test proving exact safety-field preservation.
