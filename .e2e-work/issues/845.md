# #845 — [BatteryService][AI] HTTP fallback accepts malformed 200 response as Normal prediction

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/845

---

## Component
BatteryService AI HTTP client

## Evidence
`AiPredictionHttpClient.cs:39-78` and `AiPredictionResult.cs:78-86` default missing numeric/string fields and unknown classification instead of validating the response contract.

## Controlled reproduction
Return HTTP `200 {}`. The client returns non-null: SOH=0, Classification=Normal, Priority=None, ModelVersion empty.

## Impact
The worker can persist SOH 0 as Normal and suppress an alert instead of treating malformed AI output as a transport failure.

## Expected / acceptance
Deserialize a strict required DTO, validate ranges/enums/version, reject malformed success bodies into fallback/retry/circuit logic, and test empty/partial/unknown/non-finite responses.
