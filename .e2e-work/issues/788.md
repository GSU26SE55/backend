# #788 — [Infrastructure][FileStorageService][Security] Production MinIO is public with default credentials and anonymous bucket

Priority: priority: P1
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/788

---

## Phần bị lỗi
Production infrastructure / MinIO / FileStorageService.

## Bằng chứng
- `docker-compose.prod.yml:138-144`: fallback `minioadmin/minioadmin`, expose API 9090 và console 9091.
- `docker-compose.prod.yml:165-167`: chạy `mc anonymous set download` cho toàn bộ bucket.
- `env.prod.example:78-79` cũng dùng credential mặc định.
- Helm MinIO values/init áp dụng cùng anonymous-download policy.

## Ảnh hưởng
Attachment ticket, maintenance photo và object riêng tư có thể bị tải trực tiếp không qua JWT khi biết object key. Nếu production thiếu secret, console/API có thể bị chiếm bằng credential mặc định. Lỗi này bypass hoàn toàn authorization của FileStorageService và khác issue API IDOR #723.

## Expected
- Không có fallback credential production.
- Console/MinIO API không public ngoài mạng tin cậy.
- Bucket chứa private object phải private; download qua presigned URL/authorized API.
- Nếu cần avatar/public asset, tách bucket/prefix và policy rõ ràng.

## Acceptance criteria
- Deployment fail-fast khi thiếu secret mạnh.
- Anonymous GET private object bị 403.
- External access tới console bị chặn.
- Security test chứng minh private attachment chỉ tải qua luồng được authorize.
