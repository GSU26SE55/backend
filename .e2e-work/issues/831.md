# #831 — [BatteryService][IoT][MQTT] Topic battery serial is not authoritative

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/831

---

## Component
MQTT telemetry identity binding

## Evidence
The topic parser extracts `solar/{deviceCode}/{batterySerial}/telemetry`, but when the payload contains a battery identity the handler resolves and writes the payload battery instead of requiring equality with the topic serial.

## Reproduction
Publish on a BAT-A topic with a valid body naming BAT-B. The reading is accepted for BAT-B when other checks pass.

## Expected / acceptance
Require topic serial, payload identity and authorized device mapping to agree; reject mismatches before persistence and emit a security/audit signal; add QoS1 broker regression tests.
