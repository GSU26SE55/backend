# #724 — [BatteryService][IoT][Security] Device API keys are stored and returned in plaintext

Priority: priority: P1
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/724

---

## Tóm tắt
API key thiết bị được lưu dạng rõ trong DB và trả lại ở API GET, trái contract chỉ lưu hash và chỉ trả secret một lần.

## Bằng chứng
- Contract: `IIotApiKeyService.cs:11-14`
- Ghi plaintext: `CreateIotDeviceCommandHandler.cs:50-52`, `IotDeviceCommandHandlers.cs:113-116`
- Persist column: `IotDevice.cs:36-44`, `IotDeviceConfiguration.cs:46-54`
- Re-expose: `IotDeviceMapper.cs:33-64`.

## Cách tái hiện
Tạo/rotate key, sau đó đọc row DB hoặc GET admin device by id; raw credential vẫn có thể lấy lại.

## Mong đợi
Chỉ lưu hash, secret hiển thị đúng một lần khi create/rotate, revoke/rotate dữ liệu legacy và không serialize plaintext.

## Ảnh hưởng
DB/read compromise cho phép giả mạo thiết bị và ingest telemetry.
