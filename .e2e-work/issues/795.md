# #795 — [NotificationService] Template test-send publishes email before audit transaction commits

Priority: priority: P3
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/795

---

## Phần bị lỗi
Admin notification template test-send.

## Bằng chứng
`AdminNotificationTemplatesController.cs:271-281` publish email trước; audit record và `SaveChangesAsync` chỉ chạy tại dòng 283-300.

## Failure mode
DB save fail sau broker nhận event → HTTP 500, email vẫn gửi, durable audit không tồn tại; admin retry sẽ gửi lần nữa.

## Expected
Service không dùng outbox phải commit state/audit trước publish, hoặc ghi outbox trong cùng transaction.

## Acceptance criteria
- Fault-injection DB failure không publish email.
- Success có audit + exactly one email event.
- Controller/handler tuân thủ transaction boundary chung.
