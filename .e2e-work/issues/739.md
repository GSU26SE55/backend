# #739 — [IoT][Test Tooling] Simulator payload is incompatible with the mock backend JSON casing

Priority: priority: P3
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/739

---

## Tóm tắt
Simulator dùng PascalCase (`Items` và field con) còn mock backend FastAPI yêu cầu camelCase (`items`). Do đó bộ E2E IoT nội bộ trả 400 dù real ASP.NET bind case-insensitive.

## Bằng chứng
`tools/simulator/esp32_simulator.py:52-61,156-164`; mock backend schema `tools/mock-backend/...:141-242`.

## Tái hiện
Chạy simulator trỏ mock backend; response 400 báo field `items` required.

## Mong đợi
Dùng một canonical JSON contract hoặc alias/case-insensitive validation; thêm contract test simulator <-> mock <-> BatteryService.
