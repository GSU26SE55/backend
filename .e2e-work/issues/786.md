# #786 — [IoT][MQTT][Infrastructure] Root Compose Mosquitto healthcheck is permanently unhealthy

Priority: priority: P3
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/786

---

## Tóm tắt
Broker xử lý authenticated QoS1 và Battery bridge đã connect, nhưng container root compose luôn `unhealthy` vì healthcheck dùng `/dev/tcp`, tính năng không được BusyBox shell trong image hỗ trợ.

## Bằng chứng runtime/source
- `docker inspect` health probes exit 1: `sh: can't open /dev/tcp/127.0.0.1/1883: no such file`.
- Trong cùng thời điểm authenticated publish exit 0 và Battery log `connected to broker, 4 subscriptions`.
- `docker-compose.yml:139-144` dùng `timeout 2 sh -c '</dev/tcp/127.0.0.1/1883'`.

## Phân biệt issue cũ
#744 nói compose dev/infra có false-healthy do `|| exit 0` và auth sai. Issue này là root compose false-unhealthy do shell không hỗ trợ `/dev/tcp`.

## Acceptance criteria
- Dùng probe được image hỗ trợ, tốt nhất authenticated publish/sub với credential health riêng.
- Broker healthy khi thật sự usable, unhealthy khi listener/auth path hỏng.
- Dependency/CI smoke test cả positive và negative.
