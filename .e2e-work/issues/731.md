# #731 — [Shared][Security] System.IO.Packaging 6.0.0 exposes all APIs to two high-severity advisories

Priority: priority: P1
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/731

---

## Tóm tắt
`SharedInfrastructure.csproj:32` dùng ClosedXML 0.102.2 kéo `System.IO.Packaging` 6.0.0. NuGet audit báo hai advisory High: GHSA-f32c-w444-8ppv và GHSA-qj66-m88j-hmgj; dependency hiện diện trong API runtime deps.

## Tái hiện
`dotnet list shared/src/SharedInfrastructure/SharedInfrastructure.csproj package --vulnerable --include-transitive`.

## Mong đợi
Nâng ClosedXML/System.IO.Packaging đến bản vá, regression test mọi luồng export Excel và xác nhận không còn advisory trên toàn solution.
