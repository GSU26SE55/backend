# #742 — [IoT][BatteryService] DS18B20 external-temperature readings create false SensorMismatch alerts

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/742

---

## Tóm tắt
DS18B20 gửi voltage/current/SOC=0 với source external-temp. Backend cross-source matcher ghép mọi gateway reading với BMS gần nhất mà không lọc sensor code/source rồi so voltage trước, tạo SensorMismatch giả.

## Bằng chứng
IoT `src/sensors/ds18b20.cpp:111-119`; backend `CrossSourceValidationService.cs:67-92`, `AnomalyRules.cs:217-229`.

## Tái hiện
Gửi external-temp reading cạnh BMS 12V/48V. Backend so 0V với BMS và tạo mismatch.

## Mong đợi
Contract riêng cho temperature hoặc nullable measurements; matcher chỉ so cùng measurement/source capability. Thêm end-to-end test DS18B20 + BMS.
