# #807 — [BatteryService][IoT] Provision and heartbeat accept invalid operational values

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/807

---

## Phần bị lỗi
IoT provisioning và heartbeat validation.

## Runtime repro
- Provision với firmwareVersion rỗng trả 200 và activate device với current firmware rỗng.
- Heartbeat với rssi=999, freeMemory=-1, uptime=-5, queue=-9, cpu=1000, disk=-10, temperature=500, memory=-1 trả 200 và persist.

## Nguyên nhân
`DeviceLifecycleCommands.cs:10-83` không `IValidatable`; `DeviceLifecycleHandlers.cs:53-62,148-176` ghi thẳng dữ liệu. Docs đã nêu bounds nhưng runtime không enforce.

## Ảnh hưởng
Health/dashboard/alert data bị corrupt; uptime/queue âm và percentage >100 phá operational decisions.

## Expected
Reject request invalid bằng 400 với field errors; provision cần firmware/device identity hợp lệ.

## Acceptance criteria
- Define/enforce bounds đồng nhất docs, HTTP và MQTT path.
- Boundary tests min/max/NaN/negative/extreme.
- Invalid request không mutate device.
