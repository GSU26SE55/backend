# #810 — [BatteryService][IoT][MQTT] LWT parser treats any payload containing offline as device offline

Priority: priority: P2
State: OPEN
URL: https://github.com/GSU26SE55/backend/issues/810

---

## Phần bị lỗi
Battery MQTT bridge Last Will status parsing.

## Bằng chứng
`MqttBridgeBackgroundService.cs:231-245` dùng `payload.Contains("offline")`.

Payload như `not-offline`, debug text, hoặc JSON chứa từ offline đều có thể chuyển Active device sang Offline và tạo alert.

## Expected
Parse exact trimmed protocol token hoặc versioned JSON schema; unknown/malformed status phải reject/log, không mutate state.

## Acceptance criteria
- Exact `offline` thực hiện transition.
- `not-offline`, `offline-debug`, JSON malformed không chuyển state.
- Contract test firmware publisher ↔ Battery parser.
- Duplicate LWT idempotent, không spam alert.
